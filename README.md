# 酷狗概念版 · MyGo Music 插件

在 [MyGo Music](https://github.com/egoist/mygo-music) 里听酷狗概念版。插件直接用概念版（appid 3116）的协议请求酷狗，不需要另外跑 API 服务或任何程序。

## 安装

设置 → 插件 → **+** → 从本地安装，选这个 zip（或解压后的文件夹）。安装时允许它访问列出的酷狗域名。

## 功能

- 扫码登录（酷狗音乐或酷狗概念版 App 扫）
- **每日自动领取概念版免费 VIP**（登录后每天一次，并尝试升级），「我的主页」里可以手动再领、查看 VIP 到期时间；设置里填 `0` 关闭
- 首页：每日推荐、推荐歌单、新歌速递
- 排行榜、私人FM / 小众FM（电台，一直放）
- 搜索歌曲、专辑、歌手、歌单，搜索联想
- 专辑、歌手页面，歌单（公开歌单与自己的歌单）
- 红心：「我喜欢」与 App 同步，可加心/取消
- 自己的歌单：新建、改名、删除、加歌、删歌；收藏 / 取消收藏别人的歌单
- 最近播放：播放时上报到酷狗听歌历史，与 App 同步
- 播放：标准 / 高品质 / 无损，按设置的音质依次降级
- 逐字歌词（KRC），有翻译时一并显示；没有 KRC 时退回 LRC
- 歌曲评论

## 说明

- 首次使用时插件会向酷狗注册一个设备（和概念版 App 一样），之后才能取到播放地址；注册信息只存在插件自己的数据里。
- 能不能播、能播什么音质取决于你的账号：未登录只能播免费歌曲，VIP 歌曲需要登录并领取 VIP。
- 「默认收藏」和「我喜欢」是酷狗自带的列表，不能删除。
