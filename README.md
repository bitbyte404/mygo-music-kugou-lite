# 酷狗概念版 · MyGo Music 插件

在 [MyGo Music](https://github.com/egoist/mygo-music) 里听酷狗概念版。插件直接用概念版（appid 3116）的协议请求酷狗，不需要另外跑 API 服务或任何程序。

## 安装

设置 → 插件 → **+** → 从 GitHub 安装，填 `bitbyte404/mygo-music-kugou-lite`；也可以下载 zip 从本地安装（选 zip，或解压后直接含 `plugin.json` 的文件夹）。安装时允许它访问列出的酷狗域名。

更新：仓库发布新版本后，在插件列表里点更新即可。

## 功能

- 扫码登录（酷狗音乐或酷狗概念版 App 扫）
- **每日自动领取概念版免费 VIP**（登录后每天一次，并尝试升级），「我的主页」里可以手动再领、查看 VIP 到期时间；设置里填 `0` 关闭
- 首页：每日推荐、推荐歌单、新歌速递；登录后还有「最近播放」
- 排行榜、私人FM / 小众FM（电台，一直放）
- 侧栏「发现音乐」：AI 推荐（含「和你最近听的相似」）、歌单广场（按场景 / 主题 / 语种 / 风格 / 心情 / 年代分类）、新碟上架（华语 / 欧美 / 日本 / 韩国）、场景音乐（助眠、车载、运动……）、主题歌单、歌手分类（按地区和男 / 女 / 组合）、热门搜索（点关键词直接看搜索结果）；收藏过别人的歌单时还会推荐相似歌单
- 「我的主页」：我的听歌排行（本周 / 全部）、已购单曲
- 搜索歌曲、专辑、歌手、歌单，搜索联想
- 播放不了的歌显示为灰色：搜索结果、「我喜欢」、自己的 / 收藏的 / 公开歌单、专辑、歌手、每日推荐、排行榜、最近播放、发现页面和有声书章节都会标出来。依据是酷狗版权接口对每首歌的判定（被酷狗拒绝播放的，例如地区或版权限制、已下架），VIP 歌曲在领取概念版 VIP 后能播，所以不会变灰；结果缓存半小时
- 专辑、歌手页面，歌单（公开歌单与自己的歌单）
- 关注 / 取消关注歌手（歌手页的关注按钮与 App 同步）；「我的主页」→「关注的歌手」查看已关注的歌手
- 红心：「我喜欢」与 App 同步，最新添加的排在最前，可加心/取消
- 自己的歌单：新建、改名、删除、加歌、删歌、拖动调整歌曲顺序（与 App 同步）；收藏 / 取消收藏别人的歌单
- 自己的歌单和「我喜欢」按 App 里的顺序显示
- 最近播放：首页和侧栏都有，按播放时间从新到旧排列；播放时上报到酷狗听歌历史，与 App 同步
- 有声书（长音频）：侧栏「有声书」有今日推荐、本周上新、免费 / 热门 / 飙升榜、会员精选和分类；搜索里可以搜「播客」找有声书和电台节目，打开后分页列出全部章节，免费章节可直接播放（酷狗没有提供订阅有声书的接口，所以暂不支持订阅）
- 音乐云盘：侧栏「音乐云盘」查看并播放自己上传到酷狗云盘的歌（暂不支持上传和删除）
- 播放：标准 / 高品质 / 无损，按设置的音质依次降级；音质选「无损」时优先 Hi-Res（24bit FLAC），没有再退到普通无损
- 逐字歌词（KRC），有翻译时一并显示；没有 KRC 时退回 LRC
- 歌曲评论，可以发表评论（以你的账号公开发布）
- 封面统一取酷狗 CDN 已缓存的 400 像素图，加载更快

## 说明

- 首次使用时插件会向酷狗注册一个设备（和概念版 App 一样），之后才能取到播放地址；注册信息只存在插件自己的数据里。
- 能不能播、能播什么音质取决于你的账号：未登录只能播免费歌曲，VIP 歌曲需要登录并领取 VIP。
- 「默认收藏」和「我喜欢」是酷狗自带的列表，不能删除。

## 暂不支持

酷狗没有提供接口（MyGo 本身支持，以后有接口再加）：

- 收藏专辑、查看收藏的专辑
- 订阅有声书、给有声书单集点赞
- 给评论点赞
- 远程控制其他设备播放

MyGo 不支持（酷狗 App 有）：

- MV / 视频
- Hi-Res 标识（Hi-Res 能播，只是显示为无损）
- 楼中楼回复、专辑和歌单评论（MyGo 只有歌曲评论）
- 一起听、弹幕、音效、云盘上传、乐谱、登录设备管理
